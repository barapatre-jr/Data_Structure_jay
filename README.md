# 🔗 Practical 8 – Linked Lists

Practical 8 focuses on different types of linked lists.

## 8.1 Singly Linked List

**File:** `08.1_singly_linked_list.py`

A singly linked list consists of nodes where each node contains data and a reference to the next node.

## 8.2 Doubly Linked List

**File:** `08.2_doubly_linked_list.py`

A doubly linked list contains nodes with references to both the previous and next nodes.

This allows traversal in both directions.

## 8.3 Circular Linked List

**File:** `08.3_circular_linked_list.py`

In a circular linked list, the last node points back to the first node, creating a circular structure.

# 📚 Practical 9 – Stack

Practical 9 focuses on the stack data structure.

## 9.1 Stack Implementation

**File:** `09.1_stack_implementation.py`

This program demonstrates the implementation and basic operations of a stack.

A stack follows the:

> **LIFO – Last In, First Out**

principle.

Common stack operations include:

* Push
* Pop
* Peek/Top
* Checking whether the stack is empty

## 9.2 Infix to Postfix

**File:** `09.2_infix_to_postfix.py`

This practical demonstrates the conversion of an infix expression into postfix notation using a stack.

### Example

```text
Infix:   A + B
Postfix: AB+
```

This is a practical example of how stacks are used in expression processing.

# ⚙️ How to Run

## Step 1 – Install Python

Make sure Python 3 is installed on your system.

Check the installed version:

```bash
python --version
```

---

## Step 2 – Clone the Repository

```bash
git clone https://github.com/barapatre-jr/Data_Structure_jay.git
```

Then move into the project directory:

```bash
cd Data_Structure_jay
```

---

## Step 3 – Install NumPy

Some programs in this repository use NumPy.

Install it using:

```bash
pip install numpy
```

---

## Step 4 – Run a Practical

For example:

```bash
python 01_student_data_system.py
```

Or:

```bash
python 07.1_linear_search.py
```

You can run any program using:

```bash
python filename.py
```
